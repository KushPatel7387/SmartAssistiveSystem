# Build instructions for tcs34725

![Photo](https://github.com/PrototypeZone/ceng317/blob/main/hardware/projects/media/tcs34725.jpg)

The target audience is a CENG student from any post-secondary that would like to recreate this project that reads live RGB + clear values from a TCS34725 colour sensor over I²C using a Raspberry Pi, displays the readings in the terminal, and performs simple colour classification (for example, detecting red vs. green objects).

## Materials

[Order parts from Digikey](https://github.com/PrototypeZone/ceng317/blob/main/hardware/digikeyorder.md)  
[Order PCB](https://github.com/PrototypeZone/ceng317/tree/main/hardware/pcb)  
[Order plastic case](https://github.com/PrototypeZone/ceng317/tree/main/hardware/lasercutting)  

Additional parts used in this build:

- Raspberry Pi (any model with I²C support; tested on Raspberry Pi 4)  
- TCS34725 colour sensor breakout board (I²C, address 0x29)  
- 4 × female–female jumper wires (3.3 V, GND, SDA, SCL) or header pins to mate with the PCB  
- USB-C or micro-USB power supply for Raspberry Pi  
- Micro-SD card with Raspberry Pi OS  
- Acrylic case for mounting the sensor (laser-cut from the provided files)  

Assembly steps:

1. Solder header pins onto the TCS34725 breakout (if required).  
2. Solder and inspect the main PCB following the course PCB design.  
3. Plug the TCS34725 board into the PCB headers or connect it directly with jumpers.  
4. Mount the PCB and sensor into the acrylic case so the sensor is facing outward and exposed to light.  
5. Connect the Raspberry Pi to the PCB using the I²C and power pins (as per the course wiring diagram).

## Software

### Required system packages

On Raspberry Pi OS, install/update these packages first:

- I²C tools and SMBus support  
  - `sudo apt update`  
  - `sudo apt install -y i2c-tools python3-smbus python3-pip`  

- Enable I²C interface  
  - `sudo raspi-config` → *Interface Options* → *I2C* → **Enable**  
  - Reboot the Pi.  

- Verify that the sensor is detected at address `0x29`:  
  - `sudo i2cdetect -y 1`  
  - You should see `29` in the address table.

### Python libraries

From a terminal:

- `pip3 install smbus2` *(if using smbus2)*  
- (Optional) `pip3 install adafruit-circuitpython-tcs34725` if you prefer using Adafruit’s high-level driver.

Put `tcs34725.py` in your `/hardware` folder alongside your other project files.
