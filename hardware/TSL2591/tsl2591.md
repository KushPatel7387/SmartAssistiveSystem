# Build instructions for TSL2591

![TSL2591](https://github.com/KushPatel7387/SmartAssistiveSystem/blob/master/hardware/tsl2591.jpg?raw=true)

The target audience is a CENG student from any post-secondary institution who would like to recreate this project using the TSL2591 High Dynamic Range Light Sensor.  
This guide explains the materials, software setup, wiring, code, troubleshooting, and future work needed to integrate the TSL2591 with a Raspberry Pi using the Qwiic/Stemma QT interface.

## Materials

Every CENG 317 student already has (from earlier semesters and course kits):

Raspberry Pi Extreme Kit  
SD card + reader  
Sense HAT  
USB network adapter + Ethernet cable  
2N3904 / 2N4124 NPN transistor  
220 Ω and 2.2 kΩ resistors  
5 mm red LED  
Stacking header for Pi HAT  
Grove/Qwiic connectors and cables  
16 mm standoffs + M2.5 screws  
3 mm acrylic sheets for laser cutting  
Lead-free solder, tools, safety glasses

Troubleshooting
Generic

Plus any student/project-specific comments:

Ensure I²C is enabled in raspi-config

Use i2cdetect -y 1 to confirm the sensor appears at 0x29

If readings stay at zero, adjust gain or integration time in software

Ensure enclosure cutouts allow enough light into the sensor

Check wiring order: GND, 3V3, SDA, SCL
