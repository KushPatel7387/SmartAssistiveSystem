# Overview
The target audience is a CENG student from any post-secondary program who wants to recreate this project that uses a TSL2591 High Dynamic Range Light Sensor connected to a Raspberry Pi over I²C to measure ambient light levels.

## Troubleshooting

[Generic](https://github.com/PrototypeZone/ceng317/blob/main/hardware/troubleshooting.md)

plus any student/project-specific comments:

- Ensure I²C is enabled in `raspi-config`.
- The TSL2591 should appear at address **0x29** when running `i2cdetect -y 1`.
- If readings are zero, adjust gain or integration time in software.
- Ensure that the acrylic case does not block the light sensor window.
- Verify Qwiic cable orientation (GND, 3V3, SDA, SCL).
