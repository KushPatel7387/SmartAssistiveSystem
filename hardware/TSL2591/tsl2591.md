# Build instructions for TSL2591

![TSL2591](https://github.com/KushPatel7387/SmartAssistiveSystem/blob/master/hardware/tsl2591.jpg?raw=true)

The target audience is a CENG student from any post-secondary institution who wants to recreate this project.  
This document provides the materials, setup steps, software dependencies, and troubleshooting guidance needed to get the sensor fully operational with a Raspberry Pi.

---

## Materials

- Sensor module: TS2591  
- Raspberry Pi Version 1(or equivalent)  
- Soldered PCB (optional depending on build)  
- USB-C power supply  
- MicroSD card (16 GB or higher)
