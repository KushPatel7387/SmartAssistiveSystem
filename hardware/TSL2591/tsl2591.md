# The TSL2591 High Dynamic Range Light Sensor
![Photo](https://github.com/PrototypeZone/ceng317/blob/main/hardware/projects/media/tsl2591.jpg)

# Overview
The target audience is a CENG student from any post-secondary program who wants to recreate this project that uses a TSL2591 High Dynamic Range Light Sensor connected to a Raspberry Pi over I²C to measure ambient light levels.
