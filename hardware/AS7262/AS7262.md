# Build instructions for AS7262 Spectral Sensor

The target audience is a CENG student from any post-secondary program who would
like to recreate this project that adds an **AS7262 spectral light sensor** to
the standard CENG 317 Raspberry Pi interface board and streams live readings to
Firebase / Empyrebase for use in the Smart Assistive System Android app.

Repository path for this sensor:

`hardware/AS7262/as7262.py`

---

## Materials

Every CENG 317 student already has (from earlier semesters and the course kits):

- Raspberry Pi Extreme Kit (Pi, power supply, case, etc.)
- SD card + SD card reader
- Sense HAT
- USB network adapter + Ethernet cable
- 2N3904 or 2N4124 NPN transistor
- 220 Ω and 2.2 kΩ resistors
- 5 mm red LED
- Stacking header for Pi HAT
- Grove/Qwiic connectors and cables (as ordered in CENG 317)
- 16 mm standoffs and M2.5 screws
- 3 mm acrylic for enclosure (laser cut)
- Lead-free solder and basic hand tools
- Safety glasses

Reference documents from the course:

- [Order parts from Digikey](https://github.com/PrototypeZone/ceng317/blob/main/hardware/digikeyorder.md)  
- [Order PCB](https://github.com/PrototypeZone/ceng317/tree/main/hardware/pcb)  
- [Order plastic case](https://github.com/PrototypeZone/ceng317/tree/main/hardware/lasercutting)

- [Raspberry Pi Image](https://github.com/PrototypeZone/ceng153/blob/main/image.md)  

### Additional parts specific to this project

- 1 × **AS7262 spectral sensor breakout**  
  (visible-light version of the AS726x family, I²C address `0x49`)
- 1 × Qwiic cable or Qwiic-to-wires cable
- Optional: extra standoffs / screws to mount the AS7262 board to the acrylic
  case so it has a clear optical path for light.

### PCB and enclosure notes (KiCad + laser cutting)

- Start from the CENG 317 **Raspberry Pi HAT** KiCad template provided by the
  professor.
- Route the standard **BJT switch + LED** circuit (2N3904/2N4124, 2.2 kΩ base
  resistor, 220 Ω LED resistor) as in the course notes.
- Add a 4-pin **Qwiic connector** near the edge of the board and connect it to:
  3V3, GND, SDA, SCL.
- Add mounting holes so that the AS7262 board can be attached to the enclosure
  using standoffs.
- Use the course instructions for:
  - generating Gerbers and drill files,
  - zipping and uploading your board to `/hardware/pcb/`,
  - and getting it manufactured in-house.

For the acrylic case, customize the tiles using Inkscape as described in the
laser cutting documentation, and make sure there is a cut-out / window for the
AS7262 to “see” the ambient light.
