# SmartAssistiveSystem
### Software Project – Group 5

## 📌 Overview
SmartAssistiveSystem is an application to help **visually impaired people navigate safely**.  
It uses sensors with a Raspberry Pi to detect obstacles, light, color, and surroundings, then gives **real-time feedback** to the user.

## 🛠️ Hardware
- TSL2591 – Light sensor
- TCS34725 – Color sensor
- VL53L1X – Distance sensor
- AS7262 / AS7341 – Spectrum sensor
- Raspberry Pi – Controller
